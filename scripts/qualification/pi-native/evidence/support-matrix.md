# Pi support and observed compatibility

> **Historical / superseded.** This matrix records the former static-delivery qualification and is not current package-lifecycle guidance. Use `docs/pi-delivery.md` and installed-artifact qualification for the Pi-owned npm path.

As of 2026-10-02, implementation and bounded functional testing support the observations below. The owner chose this finite closeout instead of restarting the exhaustive qualification matrix. **No formal release-support label or publication approval follows.**

The tested environment was Linux ARM64, Node 22.22.1 and external Pi 0.87.1, with Patronus-delivered tk 0.3.2, pi-subagents 0.72.1 and pi-web-access 0.35.0. It used the previously built, hash-bound local payloads and Patronus binary at product commit `234ac890b48d998624a437cace16fc183157a7c4`.
