# House writing style for Codex

For reader-facing prose, avoid em-dashes. Prefer a comma for an aside, parentheses
for a qualification, a colon for an introduction or a full stop for a second
thought. Headings may use a dash when it reads clearly. Keep punctuation outside
closing quotation marks so the quoted text stays exact: the flag is "fail-closed".

For prose that reasons or teaches, decide the meaning before the sound. Ground
abstract claims in mechanisms and consequences, keep the actor/action visible,
separate observation from inference, and scale claims to observed evidence.
Explain from the subject's structure; use contrast only to close a plausible,
consequential misreading. Keep transitions that show a real relationship and cut
filler or repeated summaries. Preserve the author's voice and exact facts.

This pointer is self-contained advisory guidance. It invokes no editorial worker,
requires no unreadable sibling and grants no authoring, file writes or fanout.
An optional editorial skill needs a separate host-compatibility audit and grant
before use. Style editing must not alter requirements, license text or authority.
