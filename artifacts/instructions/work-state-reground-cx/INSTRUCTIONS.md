# Recover Codex work context (advisory, no hook)

Initially and after resume/compaction, reread the approved brief, latest lead
handoff/decisions and effective project instructions. Inspect actual source
root/base/head, dirty/untracked state, stage grants, file owners, predecessor
settlement, remaining budgets and saved output bytes/hashes. Read project lessons
where actually present. Report drift; never infer a grant from stale chat history.

Codex has no task-specific mission API assumed here. Use the project's existing
authorized records and available native worker status/wait controls. Read every
returned report and patch before treating work as delivered. A status, filename
or dispatch receipt cannot substitute for the complete artifact.

Do not replay completed work, relaunch a live worker, overwrite another owner's
outputs or create a competing scheduler/tracker. Only the authorized lead updates
shared progress records and admits transitions. Missing state, unclear liveness
or required persistence failure blocks continuation; preserve partial evidence
and ask the lead. Never silently change model/provider/protocol/isolation.

This is advisory recovery guidance, not a SessionStart hook, automatic loader,
background polling process or guarantee of always-on continuation.
