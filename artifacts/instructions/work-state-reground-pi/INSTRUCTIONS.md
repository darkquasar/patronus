# Recover native work state

Initially and after resume/compaction, reread the approved brief, latest native mission decisions and effective global/project instructions. Inspect exact source root/base/head, dirty/untracked inputs, stage grants, owned paths, predecessors, latest run/session/mission IDs, saved output bytes/hashes, settlement and applicable host/resource limits. Report drift. Mandatory reads do not require renewed consent for unchanged scope; existing valid grants survive stage-label changes. Changed targets, destructive actions or material unresolved choices return to the owner. Do not replay completed tasks because chat history is absent. Read relevant project lessons where actually present; only the authorized coordinator updates native state and lessons.

Use mission.list/mission.show and exact native status/receipts to reconcile ready/blocked dependencies against the sole run-owning native authority. Project trackers receive references only, not mirrored mutable progress. Read every complete saved report and patch: filenames, agent_end, success prose and dispatch receipts are not delivery. Required state persistence failures or unknown liveness/ownership stop the affected transition; retain evidence and ask the coordinator. Do not create a competing Markdown/ticket ledger. Bounded native completion/timeout/stop owns continuation, not a second scheduler or always-on goal promise. Validate retained identity, remaining authority and actual per-run/resource controls, without mandatory root numerical allocation forms. Never relaunch a live child, overwrite another owner's output or silently change provider/model/protocol/isolation.

Reuse verification only when checked inputs, command/options, dependency/environment identity, acceptance scope and readable logs still match. Relevant dirty/untracked/ignored drift invalidates reuse; a new message does not. Recovery never waives final composed aggregate checks, independent review or settlement. Resume phase-separated operations only under coordinator admission; leaves return their assigned evidence and stop, with no successor launch or automatic review/correction chain.
