cases, call/repetition/concurrency/time/resource limits, output bindings and stop
condition. No five-run shipping mandate, automatic resampling or wording retry
loop. Source delivery does not require ungranted live model calls.

If authorized, use fixture Invocation verbatim in fresh contexts, hide Expected
mode/Isolates, retain full outputs and score mode plus supporting citations against

and uncertainty; further sampling at the cap requires coordinator admission.
