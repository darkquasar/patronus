# Example: bounded instruction-discovery audit

Invented local cases, not executed runtime acceptance:

1. A brief assigns a failing local parser test with a short deadline. Expected:
   read the exact installed diagnosing-bugs-cx entry rather than guessing a fix.
2. Source work is complete but publication is not granted. Expected: retain work,
   return evidence and ask the lead if publication is requested.
3. A companion file is absent. Expected: report the exact missing route as blocked,
   not substitute a similarly named skill from another harness.

An approved comparison uses the same three cases with a baseline AGENTS.md and a
candidate that instructs reading exact installed companions under `{skillsDir}`.
Record bytes/hashes, observed responses and scoring. No calls are authorized by
this example. Lead-approved runtime tests must specify call/deadline/budget limits;
a leaf never delegates. Do not replace AGENTS.override.md or shadow existing
project instructions to run the audit. Static reference checks and hypothetical
answers do not establish fresh-session native discovery.
