# Implementer or fixer leaf brief

The coordinator supplies: absolute allocated root/base/head; approved requirement
anchors and exact owned/excluded paths; accepted interfaces and predecessor inputs;
strategy/defaults and authorized check commands/resource controls; acceptance and
native return format. Model choice follows existing owner/harness policy, not an
automatic cheaper/more-capable substitution.

Read effective instructions, brief and current source before writing and after
resume. Verify the allocated root and direct every tool there. Implement only the
assigned behavior or accepted batch of corrections. Never delegate, admit reviewers,
mutate shared progress, commit, integrate, publish or clean up absent an exact grant.
Use critical public-behavior TDD, default TDD for other behavior, green coverage/
characterization for behavior-preserving refactors and focused postchecks for
nonbehavioral work as specified in SKILL.md. Omission uses those defaults and records
selection, not a mandatory approval stop. Genuine ambiguity returns to the owner.

Run authorized focused checks and read complete output; preserve actual exits and
readable logs. Inline self-check is not independent review. Return the complete
report through native delivery: implemented/attempted subject, files/hashes, actual
commands/exits/logs, applicable RED/GREEN or postchecks, original finding IDs and
correction evidence, limitations and unresolved questions. A writable report file
is optional under the grant; never replace complete delivery with only a filename
or success sentence. Report DONE, DONE_WITH_CONCERNS, BLOCKED or NEEDS_CONTEXT,
then stop. No successor review/fix chain or automatic commit/full suite.
