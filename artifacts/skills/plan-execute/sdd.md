# Isolated-leaf mode

The coordinator admits each ready implementer with
[implementer-prompt.md]({skillDir}/implementer-prompt.md). Collect and settle before
serial integration. Use [task-reviewer-prompt.md]({skillDir}/task-reviewer-prompt.md)
only for an explicitly admitted named boundary, never automatically per task.
Shared-file dependencies remain ordered even with isolated contexts.

Read the lifecycle authority, testing, settlement, review/correction and completion
contract in [SKILL.md]({skillDir}/SKILL.md). It governs this mode without a separate
status ledger, per-task review chain or additional approval ritual.
