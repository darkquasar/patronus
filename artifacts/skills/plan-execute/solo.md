# Solo mode

The coordinator implements ready ordered tasks in one context, using the accepted
brief, testing defaults and selected progress authority from SKILL.md. No per-task
reviewer or tk mirror is created. Collect focused evidence as work proceeds.
Retain fresh composed aggregate checks and one independent aggregate review under
SKILL.md's bounded correction contract. Reuse matching integration evidence for
finishing. No automatic full suite, commit, publication or cleanup is granted.
