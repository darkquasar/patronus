# Independent task execution

Use workflow-implement-pi for disjoint writer lanes, a separate native integrator and native validation. The parent reads the approved plan, resolves shared design decisions, binds exact source/base and exclusive file claims, verifies effective roles and authorizes managed cleanup before dispatch. Both upstream external writer identities are choices before launch, never recovery fallbacks. Leaves implement their bounded tasks and do not delegate.

Read every final report and captured upstream patch/handoff before integration. Failed, stopped, partial or missing evidence blocks dependents. Source is clean at each allocation; never stash/ignore/clean it to admit work. Durable outputs live outside source/integration/worktrees. Native mission state/receipts/status are the sole recovery authority.

Run one fresh independent whole-branch review of exact aggregate bytes and tests using workflow-peer-review-pi. Disposition concrete findings with at most one bounded correction, no task-by-task two-cycle rituals. No retrospective review claims for corrected bytes. Required tests, authority and coverage remain gates. Publication and retained-checkout cleanup require their own grants.
