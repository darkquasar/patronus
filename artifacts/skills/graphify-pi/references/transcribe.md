# Media and transcription

Children do not download models, install media extras, invoke transcription or
select a fallback provider. A graph omitting audio/video has an explicit coverage
limit; absence of a transcript cannot prove absence of a concept.

Only the coordinator may admit transcription with explicit stage and budget
permission. Record source bytes/hash and rights, selected tool/model versions,
local versus external processing, language/domain hints, output owner, time/CPU/
RAM/disk/network limits and credential policy before effects. Reject unknown
headroom. A code-only graph grant does not include media or semantic extraction.

Keep transcript identity tied to the original media and capture time. Report
partial failures and uncertainty; do not silently treat failed files as indexed.
Review sensitive data before any external provider request. Preserve old outputs
until the separately authorized update validates new inventory and provenance.
A transcript is derived evidence and consequential claims still need source review.
